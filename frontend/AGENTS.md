# AGENT INSTRUCTIONS - EVESAT

## Project overview
This repository contains the EVESAT front-end app for a premium events & logistics management experience. The app is built with Vite, React, TypeScript, Tailwind CSS, and TanStack Router.

## Primary working areas
- Main application code lives in `src/`
- Route definitions live in `src/routes/`
- Shared UI components live in `src/components/ui/`
- Global styling and theme tokens live in `src/styles.css`
- The generated router file `src/routeTree.gen.ts` should only be updated when route structure changes and is typically regenerated by the framework.

## Local workflow
Use the existing project scripts from the root package.json:
- `bun install` to install dependencies
- `bun run dev` to start the dev server
- `bun run build` to make a production build
- `bun run lint` to validate the codebase

## Coding expectations
- Keep the existing EVESAT visual identity: dark luxury palette, gold accents, serif headings, and premium event branding.
- Prefer small, focused React components and reuse existing patterns from the current codebase instead of introducing new frameworks or abstractions.
- Maintain TypeScript correctness and avoid introducing unused variables or broken imports.
- Keep UI copy and labels in Spanish unless a user explicitly requests a different language.
- Preserve accessibility basics: meaningful labels, focus states, and semantic HTML.
- When adding new pages or route links, follow the current TanStack Router structure and naming conventions.

## File safety rules
- Do not rewrite git history or force-push branch changes.
- Do not change the Lovable connection instructions in this repository.
- Keep changes scoped to the task and avoid broad refactors without a clear reason.
- Before editing a route or shared component, check the neighboring files to match the established patterns.

## Delivery style
- Explain the change briefly and clearly.
- Prefer targeted fixes over large rewrites.
- Validate the relevant command after implementation when feasible.

## Scope note
This repo has a duplicated frontend folder under `03-DEVELOP/frontend/`. Treat the root app as the active project unless the user explicitly points to the nested frontend folder.
